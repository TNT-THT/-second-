# 洛谷小花 · 可选的 Chrome / Edge MV3 扩展

不装也能使用桌宠。桌宠默认**不监听端口**。工作台 → 感知与隐私 → 洛谷通过事件 → 阅读数据源并允许。右键 Haru 查看本次随机的 12 位配对码。

将独立扩展 ZIP 解压，在浏览器扩展管理页打开开发者模式，**加载已解压的扩展**，选中包含 `manifest.json` 的文件夹。点击工具栏上的扩展并输入配对码。配对仅保存在浏览器会话内，桌宠重启会换码。在自己打开且聚焦的 `https://www.luogu.com.cn/record/…` 页面检测 `.status.accepted` 和问题链接，只发送通过题号。同题冷却 30 分钟。在其他前台洛谷页面只发送在场信号，不发送页面地址。

接收端仅在 `127.0.0.1:38417/pet`；校验方法、Host、固定扩展 Origin、配对头、长度及数据格式。没有远程 API、遥测或历史记录权限。连接失败不会改走云端。DOM 或浏览器策略变化可能使事件不触发；这时基础桌宠照常工作。工作台可停止监听，扩展本身也可断开或移除。
