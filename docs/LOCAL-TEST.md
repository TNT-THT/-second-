PetDesk 1.1.0 · 本地测试说明
===========================

一、启动（不要在 ZIP 预览器里直接运行）

1. 解压整个下载包，保留所有子目录。
2. Windows 完整便携包：双击 PetDesk.exe，无需 Node、Python、安装或联网。
   Starter 轻量包：Windows 双击 Start-Windows.cmd；macOS 使用 Start-macOS.command；Linux 在图形桌面的终端执行 sh Start-Linux.sh。
3. Starter 首次会下载约 120–160 MB 的官方 Electron 45.3.4，核对 SHA-256 后缓存到本机。此步骤需要能访问 GitHub Releases。后续不需联网。缓存文件夹位于 %LOCALAPPDATA%/PetDesk、~/Library/Caches/PetDesk 或 ~/.cache/PetDesk。不要从陌生来源补 DLL 或关闭系统保护。
4. 你应该先看到真实桌面上一个蓝发、白裙、拿折扇的角色，而不是工作台。可将她拖到另一个显示器。Windows Starter 此后可双击同目录 PetDesk 快捷方式，避免命令窗口。

二、两分钟验收

□ 打开编辑器并保持输入光标。让她经过普通程序窗口，确认仍能打字，不会跳出工作台。
□ 点击角色或她双腿之间的小空隙，都应由她接收点击，不会点到背后窗口。小窗外可照常编辑。旧版保存的「免打扰穿透」不会沿用。
□ 先在「动作试映」看两侧步态，再试真实桌宠：按住并拖动，观察扶帽、摆腿和松手缓冲。开启漫游与边缘玩耍，放在屏幕右边偏上的位置，移开鼠标；应先攀边、再乘扇横渡。小憩时停止漫游。
□ 在工作台首页拖动「角色大小」，依次试 60%、100%、160%。衣裙、四肢和小窗一起等比变大变小，不应只拉伸一个方向。
□ 在下载目录新建一个无用的 petdesk-test.txt（不要用重要文件）。拖到她身上，先按取消，确认文件仍在。再拖一次，核对对话框里的完整路径；确认后才应出现捧碟吃饼干的动作，然后检查原位置及系统回收站。不要在无回收站或网络卷上测试。
□ 从托盘进入工作台 → 模型库，导入透明 PNG / GIF / WebP 或自包含 GLB；也可点「试用 3D 示例」。真实桌宠应同步换装，退出重开仍保留。移除模型仅删副本。
□ 右键角色 → 桌面小工具 → 下载目录/计算器。系统未装支持的计算器时只提示，不执行其他程序。
□ 关闭工作台，桌宠应仍在。再次运行同一程序能找回工作台。最后右键托盘 → 退出 PetDesk。

三、常见情况

- 没有托盘图标：Windows 看隐藏图标，macOS 看菜单栏。Linux 桌面可能未启用 AppIndicator。再次启动同一个程序也能打开工作台。
- 纯 Wayland 桌面可能限制移动/置顶；Linux 版本需 X11 或有 DISPLAY 的 XWayland，且有桌面合成器。不同合成器、任务栏及多屏缩放仍建议实机验证。
- 文件拒绝投喂：仅限系统桌面、下载、文档目录中的普通文档或图片；拒绝应用/系统目录、隐藏路径、链接、文件夹、超 100 MiB 文件。回收失败不会永久删除。
- 暂时看不到气泡：真实桌宠平时安静，只在主动互动时短暂显示。鼠标悬停时会停步回应，移开后才继续走。
- 这不是通义聊天客户端。默认角色是带动效的原创二次元立绘；没有云端模型调用、联网问答或远程控制。
- 浏览器预览不能越出浏览器，也不能删除真实文件。请运行下载包测试置顶、鼠标命中、拖放与系统回收站。
