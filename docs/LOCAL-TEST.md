PetDesk 1.2.0 · 本地验收
========================

先退出旧版（托盘 → 退出 PetDesk）。完整解压到新文件夹，不要在 ZIP 里双击，也不要只拷贝 exe。

Windows 10/11 x64 完整包：双击 PetDesk.exe。无需 Node、Python 或首次联网。
Starter：Windows 双击 Start-Windows.cmd；macOS 用 Start-macOS.command；Linux 在图形终端执行 sh Start-Linux.sh。首次从官方 GitHub 下载固定版本 Electron 并核对 SHA-256，此后离线可用。macOS/Linux 未做原生实机验收；Linux 需 X11/XWayland、合成器和 Electron 系统库。不要为了未签名测试版关闭系统保护。

□ 启动后先出现的是桌面上的 Q 版蓝发伙伴，不是工作台。打开编辑器打字，鼠标点角色会回应但键盘焦点不应被抢走；小窗外不拦点击。右键角色或托盘可进入工作台；再次启动同一个应用也可找回工作台。
□ 换装：模型库 → 藤铃紫 → 使用模型。检查真实桌宠、伙伴档案、动作试映与选中卡片颜色一致。重启保留选择。也可切回花庭蓝、导入图片或试用 3D 示例。
□ 落地：选择「步行巡游」，把她拖到屏幕中央，避开边框并松手。应先下落，碰到窗沿或桌面才屈膝回弹。关闭「自由漫游」也必须下落。开启边缘玩耍时，贴住侧边或顶部放手是抓住边缘，不是飞行。
□ Windows 窗沿：把一个普通窗口还原为非最大化、移至屏幕下半部，点它使其成为前台。确保上方能放下角色。「设置 → 窗口落脚点」开启，将角色放在该窗口顶部上方。她应落在窗沿并沿边散步；移窗、缩小或关闭窗口再看落脚点。只识别当前前台窗，不做屏幕截图。macOS/Linux 能在普通窗口之上活动，不识别其他应用的窗沿。
□ 飞行：动作手册 → 乘扇飞行 → 允许此动作；日常安排 → 自由飞行。开启自由漫游会穿过工作区内部，关闭漫游会悬停。关掉「允许乘扇飞行」应立刻退出飞行并着陆，重新允许不会自动起飞。图片及没有飞行片段的 GLB 不可选自由飞行。
□ 待机：落地，关闭自由漫游，移开鼠标。选「翻翻绘本」并等约四秒，观察开书翻页；选茶歇可端杯。禁用当前活动后不会再自动抽到；「安静待机」只呼吸眨眼。点「说说话」几次，台词应变化。
□ 在工作台首页把「角色大小」调到 60%、100%、160%，看人物与小窗一起缩放。测试多屏时请特别检查混合 DPI 和任务栏位置。
□ 投喂：在下载目录新建一个无用的 petdesk-test.txt。拖到桌宠，取消后应仍在；第二次核对绝对路径并确认，成功后离开原位置、进入系统回收站。不要用重要文件或无回收站的卷。拒绝文件夹、隐藏文件、链接、系统/应用目录和超过 100 MiB 的文件。失败不改为永久删除。
□ 右键角色 → 桌面小工具。仅主动报时、打开下载目录、启动受支持的计算器；无任意命令接口。关闭工作台不退出桌宠，要结束请右键托盘 → 退出 PetDesk。

网页的庭院和练习窗沿只是模拟器，不能移出浏览器，不能删除真实文件，也不会获取电脑窗口。真实桌宠无背景、置顶、不可聚焦，小矩形始终接收鼠标；不保证覆盖独占全屏、安全桌面或锁屏。
