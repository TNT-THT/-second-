# Haru 桌边 · Windows 本地测试

**这是原生桌宠，不是网页。** 在普通用户可写的本机文件夹完整解压 `PetDesk-2.0.0-Haru-Preview-Windows-x64.zip`，双击 `PetDesk.exe`。不需要管理员、Node、Python、下载运行库或另装 Core。不要只取出 EXE；`assets`、`config` 要跟它在一起。要快捷方式请用 Windows 的“发送到 → 桌面快捷方式”；程序不安装自启动项。

1. **第一次见面**：Haru 应在工作区底部中央，背景透明，桌面其他地方可以继续操作。首次没有状态日志，按恢复规则从 50 开始。右键 **打开陪伴工作台**，浏览概览、表达实验室、感知与隐私、画给我看、我的回忆；工作台关闭不会关闭桌宠。
2. **投喂验证**：备一份自己的 `.txt/.png/.cpp/.json`；将单个文件拖到腰部的椭圆落点再松开，或右键「投喂…」选文件。原件留在原处，内容不打开、不复制；只有类型与属性指纹。再喂一次：仍表演，24 小时窗口内不重复增加。非白名单不记账。`Ctrl+Shift+F` 只是重温味道。
3. **摸摸与移动**：单击、快速双击、停住抚摸、右键长按拖动、在腰部滚轮缩放。`Ctrl+Shift+M` 静音；`Esc` 不吞掉前台应用按键，同时让桌宠回到默认位置、尺寸、纯规则状态。可从菜单退出。「陪我工作」与「聊聊天吧」可单独体验。
4. **两个开关互不依赖**：在工作台「表达实验室」打开 15 或 16，第一次会明确列出数据源，取消就不开。试演“庆祝 / 安慰”；不可打断的动作结束后按优先级处理后续意图。拖动滑块越过安全值会回弹。自定义策略只从私有 `config/policy.json` 读取；缺少的语义会提示。红色文字也提示钳位，不要求设备支持震动。
5. **画给我看**：64×64 黑白画布；「画好了」后看画 3 秒再评价。每张用 512 字节的位图转 base64；只追加在 `data/doodles.jsonl`，**物理最多 20 张**。满后仍可看新画但不保存，不依赖删除历史来伪装“最多 20 张”。不会导出图片。徽章详情只在工作台内。
6. **可选感知**：音量仅峰值/静音、输入法仅语言与模式、色温仅 gamma 表；默认关闭。洛谷和全局输入次数分别授权。天气需本机提供城市和 WMO 天气码：见仓库 `docs/BOUNDARIES.md`。当前公开包**没有 Whisper 权重或识别后端，不会打开麦克风**。没有设备或不适用的系统信号不会弹技术错误。
7. **看数据**：`data/feed_log.jsonl` 只有 UTC `ts`、8 位元数据 `hash` 与 `type`。`state.jsonl` 每 5 秒活动时间和变化时追加；不覆盖/轮转。工作台设置也仅追加本机私有记录。退出后再启动可验证恢复；被截断的最后一条不会抹掉之前的记录。不要把新 EXE 覆盖进旧 1.x 目录；旧版不是这条安全路径。

天气示例：把 `config/weather.example.json` 复制成 `config/weather.json` 并改成你所在的城市与 WMO 天气码（61 = 小雨），保存后 24 小时内使用缓存结果。

模型来源：Live2D 官方 Native Samples `4-r.7`，完整声明见 `assets/models/haru/LICENSE`、`NOTICE.md` 和 `readme.txt`。当前可执行文件使用开源 **Purism Core** 直接求解真实 MOC3 网格，而非冒充官方专有 Core。模型自身没有中性表情文件、裙摆物理目标或春节换装；不会伪造这些资源。请遵守模型单独的素材及角色条款。
